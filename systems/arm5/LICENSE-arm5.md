# Ars Magica 5th edition spells

`arm5.json` holds the formulaic and ritual spells of the Ars Magica Fifth Edition core rulebook.

## Source

- Atlas Games released the text of Ars Magica Fifth Edition under the Creative Commons Attribution-ShareAlike 4.0 International license: https://atlas-games.com/openarm (checked 2026-11-25). The licence covers the text only, not the graphic design, trade dress, art or logos.
- The text was taken from the Markdown version by OriginalMadman, https://github.com/OriginalMadman/Ars-Magica-Open-License, file `reviewed/Ars Magica 5e - Core Rules.md` at commit 5384ec89ff2c9c201157b1df346f5d84b9452272. That repository is itself licensed CC BY-SA 4.0.
- `tools/arm5_import.py` built the library. It keeps each spell's name, Arts, level, Range, Duration, Target, requisites, ritual flag, text and level breakdown. Markdown emphasis, links and page anchors were removed; the words are unchanged.
