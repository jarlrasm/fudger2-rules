# Cypher System content

`cypher.json` contains abilities, descriptors, foci, cyphers, artifacts, equipment and creatures from the Cypher System Reference Document.

Compatible with the Cypher System.

The text comes from https://github.com/Obsidian-TTRPG-Community/Cypher-SRD-Markdown (abilities, descriptors and foci) and https://github.com/daegalus/csrd (the rest), and was converted with `tools/cypher_import.py`.

`Cypher-System-Reference-Document.pdf` is the text of the Cypher System Reference Document of 2025-08-22, as Monte Cook Games publishes it in Word format, turned into HTML with `tools/docx_to_html.py` (text, bold, italics and tables only; no images) and printed to PDF. Its headings were set from the text, since the document has no heading styles. The library's items link to its pages (`tools/pdf_references.py`).
